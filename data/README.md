# Data Directory

- `eval/test_set_200_seed.jsonl`: synthetic seed evaluation set with 200 items.
- `examples/demo_items.jsonl`: tiny demonstration file.
- `raw/`: place unprocessed external data here, but do not commit sensitive or copyrighted data.
- `processed/`: derived data created by scripts.

The 200-item seed set is meant for development and interim reporting. It should be manually audited before final submission.

## Candidate v1 processed benchmark

`data/processed/candidate_v1_2000.jsonl` is a literature-grounded candidate benchmark for the item-reviser with 2,000 rows. It is generated by:

```bash
python scripts/generate_candidate_v1_dataset.py
```

Validate it with:

```bash
python scripts/validate_eval_set.py data/processed/candidate_v1_2000.jsonl
```

The candidate artifacts in `data/processed/` are derived outputs and are ignored by Git by default. Regenerate them from the script unless they are intentionally force-added or shared as external review artifacts.
